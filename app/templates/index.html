🚗 Vehicle Detection and Counting

This project detects and counts vehicles in video frames using computer vision techniques. The core analysis logic lives in the Jupyter notebook Vehicle_Detect_&_Count.ipynb, which you can run locally to explore the detection pipeline step by step.

Project Structure

.
├── app.py                        # Flask web app entrypoint
├── app/
│   └── templates/
│       └── index.html            # This page
├── render.yaml                   # Render deployment blueprint
├── requirements.txt              # Python dependencies
├── README.md                     # Project documentation
└── Vehicle_Detect_&_Count.ipynb  # Core detection notebook

API Endpoints

  • GET / — This landing page
  • GET /health — Returns {"status": "healthy"}

Run Locally

pip install -r requirements.txt
python app.py

Then open http://localhost:8000 in your browser.
